# Procesos Globales

Esta seccion documenta flujos de negocio que atraviesan varios bounded contexts y no pertenecen por completo a un solo modulo.

## Objetivo

Registrar procesos end-to-end para que el equipo pueda entender:

- que modulo inicia el flujo
- que modulos participan
- que eventos o integraciones intervienen
- donde estan los puntos de fallo o compensacion

# Architecture Decision Records

Este directorio contiene los ADRs del proyecto ERP Core, gestionados con [Log4brains](https://github.com/thomvaill/log4brains).

Para navegar los ADRs, consultar el [índice de ADRs](./index.md).

## Desarrollo

Si no está instalado, instalar Log4brains:

```bash
npm install -g log4brains
```

Para previsualizar la base de conocimiento localmente:

```bash
log4brains preview
```

Para crear un nuevo ADR de forma interactiva:

```bash
log4brains adr new
```
